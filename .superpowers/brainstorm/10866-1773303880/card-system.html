A. 微妙边框 (Subtle Border)

极淡的背景 + 细边框 (6% 白色)，hover 时边框亮度提升到 12%。无阴影、无装饰条、无光晕。所有卡片统一圆角 16px，hover 统一 translateY(-2px)。

优点

  • 最干净，呼吸感强
  • 改动量最小

缺点

  • 视觉层次略弱

B. 毛玻璃 + 微光 (Glass & Shimmer)

半透明背景 + backdrop-filter blur + 0.5px 内光边。hover 时增加柔和阴影 + 边框色微亮。保留玻璃质感但去掉顶部装饰条和径向光晕。统一 16px 圆角，hover translateY(-2px)。

优点

  • 保留质感与深度
  • 与 Glassmorphism 2.0 主题一致

缺点

  • backdrop-filter 有性能开销

C. 层叠表面 (Elevated Surface)

实色背景 (#111116) + 柔和投影，不用 backdrop-filter。通过 bg 色阶区分层级（页面 #08080c → 卡片 #111116 → 内嵌 #1a1a22）。hover 时提升阴影深度。Material Design 3 风格。

优点

  • 性能最好
  • 层次感清晰

缺点

  • 缺少透明质感

推荐: B — 毛玻璃 + 微光

与 Glassmorphism 2.0 方向最一致。关键改进是：去掉所有顶部装饰条（accent bar）和径向光晕，只保留微妙的 blur + 内光边框。所有卡片共享同一套 hover 行为（translateY -2px + 边框提亮 + 阴影加深），不再每种卡片一套。
